# 家教小铺 · 前端

统一平台品牌、独立商家入口的家教订单平台演示界面。使用原生 JavaScript、CSS 和本地 SVG，零构建依赖；后端仓库为 `HEltDeng/jiajiao-shop-backend`。

## 运行

将两个仓库放在相邻目录，按后端 README 启动 FastAPI。前端与 `/api` 同源运行，不要仅用静态文件服务器打开，否则交易接口不可用。

## 路由

- `/`：平台总入口，输入入口码或本平台链接进入小铺，支持申请开铺。
- `/s/qinghe`：样板分入口，统一展示“家教小铺”品牌与家教单，不展示商家头像、店名、简介或其他商家。
- `/s/{slug}`：审核开通的独立店铺入口；没有平台店铺搜索。
- `/orders`：下单、模拟支付、交付、完成与售后。
- `/funds`：保证金冻结和退回记录。
- `/merchant`：家教需求发布、上下架、订单、模拟流水、店铺设置。
- `/platform`：店铺审核、暂停、订单、退款争议、流水与审计。
- `/policies`：服务规则、演示范围及隐私说明。

通过“我的订单”“商家中心”“平台管理”进入对应演示操作。同一浏览器的数据由后端持久化，7 天有效。新店铺仅在创建它的演示空间可见，分享样板入口可供每个访客建立各自空间。不是生产账号系统，也没有真实收款。

## 体验流程

选单 → 确认未勾选的规则复选框 → 创建订单 → 模拟支付 → 查看交付 → 我的订单 → 确认完成退保证金，或者申请售后 → 进入平台管理 → 退款与争议 → 审核处理。

商家入驻 → 平台审核 → 管理新店 → 发布家教单 → 打开独立入口。

## 前端校验

```sh
node --check app.js
node --test tests/entry.test.cjs
```

响应式布局适配手机、平板及桌面。交互使用语义按钮、表单标签、原生 dialog、焦点样式和 `aria-live` 提示。动态文本统一转义；所有价格及权限由后端确认。

界面采用白底、大字、等宽卡片，无插画、英文装饰或商家陈列。只有本地 SVG favicon 与功能图标，无外部资源或跟踪脚本。

入口码仅用于精确打开一个分入口，不支持商家目录或模糊搜索。链接解析拒绝外站和其他管理路由。手机为单列，平板双列，桌面三列卡片。
